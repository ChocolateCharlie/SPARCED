# SPARCED speed enhancement (Mutsuddy 2023)

This page outlines the steps taken to replicate the results from
[_Computational speed-up of large-scale, single-cell model simulations via a fully integrated SBML-based format_](https://academic.oup.com/bioinformaticsadvances/article/3/1/vbad039/7084764)
by Arnab Mutsuddy et al., published in 2023.
It includes details on the experimental setup, data preprocessing, code execution, and any deviations or clarifications needed to match the original findings.
